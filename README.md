## OpenClaw 到底需要一台什么样的机器

一句话：一台能一直开着、能装 Node.js、能访问外网的机器。

官方安装器支持 macOS、Linux 和 Windows（WSL2），会自动准备好受支持的 Node.js 运行时；习惯自己管 Node 的话，npm 安装路径要求 Node 24.16+ 或 26.1+（推荐 26）。装完之后跑的是一个 Gateway 守护进程，负责会话、工具、事件和各聊天渠道的连接。负载大头其实在模型 API 那一侧，本机只是控制面，对硬件要求不算苛刻——这也是入门规格的云电脑就能起步的原因。

还有个容易忽略的点：个人接 WhatsApp、Telegram、Slack 这类渠道时，多数场景走的是 bot 出站连接，不用给这台机器开入站端口。官方安全文档里专门有一份 exposure runbook，讲的就是什么时候才需要把 Gateway 暴露出去——日常自用，基本碰不到。

数据这块官方写得很直白：状态、记忆和凭据都存在你这台机器上，默认联网行为只有每日版本检查，匿名统计要主动开启，配置 `update.checkOnStart: false` 可以把版本检查也关掉。放在无影云电脑上，就是放在你租的这台云桌面里。

## 为什么放云桌面，而不是自己的电脑

OpenClaw 有几个特性决定了它对“常驻”有刚需：持久记忆、心跳机制（heartbeat）、定时任务和渠道消息监听，都要求机器别断。2026 年 8 月底发布的 2.0 版本把会话迁到了 SQLite 上，重启不丢历史——前提是机器一直在。

云桌面的价值就三点：

- **隔离**：OpenClaw 的工具默认直接跑在宿主机主会话里，除非你额外配沙箱。给它一台专用的云电脑，等于把 agent 的执行环境和你的私人文件隔开，浏览器自动化、命令行这些操作翻车了也不波及本机。
- **不占生活空间**：家里不用多一台嗡嗡响的机器，也不占你日常电脑的资源。
- **换机不搬家**：工作区和配置都在云端盘上，本地电脑坏了、换了，不影响这个助手。

也说说它不适合谁。只想偶尔跟 AI 聊两句的人，用网页版聊天工具就行，为这个开云电脑纯属浪费；已经有现成 Linux 服务器的人，OpenClaw 直接装上去就是；主打语音交互的人要注意——语音唤醒和 Talk Mode 在 macOS/iOS/Android 的设备端实现，云桌面本身没有麦克风场景，语音功能得靠手机或 Mac 上的 companion app 作为节点接入 Gateway。

## 系统镜像怎么选：Ubuntu 直装还是 Windows + WSL2

优先选 Linux 镜像。OpenClaw 在 Linux 上是原生安装路径，一条命令跑完就能进引导向导，没有中间层。

## 从零到挂上 Gateway 的完整流程

全程在云桌面里完成，按顺序走：

1. 开通一台无影云电脑，镜像选 Ubuntu，计费方式选包年包月（短测可用按量付费）。
2. 用客户端或浏览器连上桌面。
3. 装运行时和 OpenClaw：

bash
curl -fsSL https://openclaw.ai/install.sh | bash


4. 安装脚本会自动进入引导向导，跟着走完模型接入、工作区创建和 Gateway 配置。如果直接用 npm 装的包，手动跑：

bash
openclaw onboard --install-daemon


5. 确认 Gateway 状态，打开控制面板：

bash
openclaw gateway status
openclaw dashboard


6. 在 Control UI 里发一条消息，确认助手正常应答。
7. 接聊天渠道。WhatsApp、Telegram 这类支持私信的渠道，默认对陌生发送者走配对机制：对方收到一个配对码，你在机器上批准才生效：

bash
openclaw pairing approve <channel> <code>


官方给的整体用时说法是五分钟左右。2.0 的引导设置还会自动识别你已有的 ChatGPT 或 Claude 订阅、API key，或者本地的 Ollama 模型，不用手写配置文件。

装完之后，你日常其实很少需要再打开这台云桌面的图形界面——发消息、交代任务都在 Telegram、WhatsApp 这些渠道里完成，需要看面板时浏览器开 Control UI 就行。

## 和其他常驻方案比一比

同类的跑法主要就三种：买台 Mac Mini、用家里的旧电脑、租普通服务器。差异如下。

**Mac Mini**：社区里最流行的常驻主机，安静省电，macOS 端的语音唤醒体验也最完整。代价是一次性购机投入、硬件坏了得自己处理，放在家里还要面对供电和家用网络的连通性问题。

**家里的旧电脑**：零购机成本，但噪音、功耗都是长期账，7×24 开着心里也不踏实。

**现成的 Linux 服务器/VPS**：如果你本来就有，这是最省事的方案，OpenClaw 直接装。纯命令行环境对新手门槛高一些——这是它和云桌面最主要的差别，无影云电脑给你一个完整桌面，连接、调试、看 Control UI 都有图形界面托底。

三种方案共同的问题是：机器在你家里，断电断网就掉线；云桌面把硬件和网络这两口锅都甩给了机房。

## 几个高频问题

**OpenClaw 本身要花钱吗？**
不用。核心开源、MIT 协议，由独立的 OpenClaw Foundation 维护，没有付费版、没有托管服务、也没有代币，目前有 38 万多名开发者在用。你的开销就是机器（云电脑月租）和模型 API。

**网上看到的 Clawdbot、Moltbot 教程还能照着做吗？**
是同一个项目。2025 年 11 月以 Clawdbot 的名字火起来，2026 年 1 月底短暂改名 Moltbot，随后定名 OpenClaw。官方有专门的迁移指南，实际操作基本是改配置文件名和更新镜像标签，教程思路仍然适用。

**我的聊天记录和数据会传给谁？**
状态、记忆和凭据都存在你这台云电脑上。默认联网行为只有每日版本检查，匿名功能统计需要你主动开启。提示词只会发给你配置的模型服务商，OpenClaw 自己不做中转。

**无影云电脑会不会跑不动？**
入门规格跑单个 Gateway 足够。本机负载主要是会话管理和渠道收发，重活在外部模型那边。多渠道用一阵子后觉得吃力再升配，成本可控。
